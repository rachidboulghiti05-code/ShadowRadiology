Shadow Radiology — مشروع Android موسّع

الميزات:
- قاموس مصطلحات فرنسي/عربي مع نطق صوتي عبر محرك النطق في الجهاز (قد يتطلب تنزيل أصوات).
- مساعد محلي دون إنترنت بإجابات تعليمية مضمّنة.
- واجهة إعداد للاتصال بخادم ذكاء اصطناعي عبر الإنترنت. يتطلب خادمًا آمنًا متوافقًا؛ لا يوجد مفتاح API مضمن.
- مشهد 3D مبسط تفاعلي يُحمّل مكتبة Three.js من الإنترنت، لذلك يحتاج إنترنت عند فتحه أول مرة.
- خلفية/ألوان تتغير مع تقدم نقاط الخبرة.
- تذكير دراسي وتجربة رسائل تشجيعية صوتية.

بناء APK:
1. ثبّت Android Studio: https://developer.android.com/studio
2. فك ضغط ShadowRadiologyAndroid.zip.
3. افتح مجلد ShadowRadiologyAndroid في Android Studio.
4. اسمح بمزامنة Gradle وثبّت Android SDK Platform 35 إذا طُلب.
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
6. انقل APK إلى هاتف Android وثبّته.

ملاحظات مهمة:
- هذه حزمة مشروع قابلة للبناء وليست APK نهائيًا.
- المساعد دون إنترنت محدود إلى المعلومات المضمّنة؛ ليس نموذج ذكاء اصطناعي محليًا كاملًا.
- الاتصال التوليدي عبر الإنترنت لا يعمل إلا بعد إعداد خادم آمن. لا تضع مفاتيح API سرية في التطبيق.
- نموذج 3D تخطيطي تعليمي، وليس مجسمًا طبيًا دقيقًا. يتطلب إنترنت لتحميل مكتبة Three.js.
- تذكير الوقت يعمل بصورة محدودة أثناء فتح التطبيق/الصفحة؛ لا يُعد بديلًا عن إشعارات أندرويد المجدولة في الخلفية.


إضافة الشخصيات الكرتونية الثنائية الأبعاد:
- في الصفحة الرئيسية ستجد القلب «نبض» والطائر «ريشة».
- أزرار الصوت تشغّل العربية أو الفرنسية باستخدام الأصوات المتوفرة في الهاتف/المتصفح. قد يلزم تنزيل بيانات تحويل النص إلى كلام من إعدادات أندرويد.
- تحريك الفم تقريبي أثناء الكلام وليس مزامنة دقيقة لكل مقطع صوتي.
- لا تحتاج الشخصيات إلى صور خارجية أو إنترنت، لكن دعم النطق يعتمد على محرك الصوت المثبّت في الجهاز.

تحديث المحتوى الدراسي:
- تمت إضافة دليل «تقنيات ووضعيات التصوير» مع الإسقاطات AP وPA والجانبي والمائل والمحوري والمماسي، ووضعيات المريض وأمثلة لفحوص الصدر والبطن والحوض والعمود الفقري والأطراف.
- تمت إضافة عبارات فرنسية شائعة لتوجيه المريض مع زر النطق.
- تمت توسعة القاموس إلى أكثر من 200 مصطلح طبي/تشريحي/شعاعي مع البحث والنطق.
- هذا محتوى تعليمي أولي وليس بروتوكولًا سريريًا شاملًا؛ يجب اتباع بروتوكولات المؤسسة وإشراف أخصائي الأشعة، خصوصًا عند الإصابات أو استخدام المادة الظليلة أو الفحوص الخاصة.
